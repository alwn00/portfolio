30만 건 코호트 인과추론 — Time-varying Cox + PSM

부산대 석사 연구 · APCN 국제신장학회 1저자 발표

1저자 발표

기존 표준 모델의 한계(고정 노출 가정)를 극복하기 위해 Time-varying Cox Model로 시간에 따라 변하는 노출 특성을 반영. PSM 1:2 매칭으로 혼란 변수를 제거해 PM2.5 단위 증가 시 CKD 환자군 AKI 발생 위험 HR 1.05배 상승 증명.

데이터 · 분석 설계
  • 국민건강보험공단 2010~2019년 30만 명 코호트
  • 사망·이탈자 중도절단 처리, 1~2년 이동평균 적용한 time-varying exposure 변수 생성
  • 표본 손실 최소화를 위한 1:2 성향점수매칭
  • 성별·연령·소득 등 혼란 변수 통제, 매칭 후 그룹 간 공변량 균형 확보
결과 · 의의
  • HR 1.05 — PM2.5 단위 증가 시 AKI 발생 위험 1.05배 상승 (p<.001)
  • PSM 이후에도 RHR 1.13으로 효과 견고성 확인
  • APCN 아시아태평양신장학회 제1저자 발표
  • 코호트 시간 가변적 요인과 혼란 변수를 구분해 순수 인과 효과 증명

위성 데이터 파이프라인 × GAM 앙상블 — 예측 정확도 98%

부산대 석사 연구 · 환경부 기후변화 대응 환경보건센터 공식 채택 · 산학캡스톤 장려상

환경부 공식 채택

기상청 관측소 데이터가 자치구당 1개소로 넓은 지역을 대표하는 한계 발견. Google Earth Engine 위성 데이터로 1km² 격자 DB를 직접 구축하고, 30% 결측을 시공간 역추적 알고리즘으로 복원. GAM 앙상블로 예측 정확도 98% 달성.

파이프라인 3단계
  • [01 데이터 수집·정제] Google 위성 기반 1km 격자 DB 추출, 대기 잡음으로 인한 30% 결측치 인접 시점 농도 역추적 보간 알고리즘 적용
  • [02 예측 모델링] SVR, Random Forest, XGBoost 등 트리 기반 3종 모델 학습·검증 세트 분리 (일반화 성능 평가)
  • [03 비선형 보정] 지역별 편차·변수 간 비선형 관계 해결 위해 GAM 앙상블 + Spline 보정 결합
결과 · 재사용 설계
  • 예측 정확도 98% 달성
  • 환경부 기후변화 대응 환경보건센터 공식 예측 파이프라인으로 채택
  • R로 행정동 단위 시계열 시각화, 서울시 계절 관리제 감축 정책 효과 정량 입증
  • 구축한 DB를 재사용 가능한 구조로 설계 — 데이터 마트 정합성 검증

공식 가이드라인 채택

3년간 축적된 비정형 데이터와 파편화된 엑셀 파일에서 1,703명 전수조사 패널 DB를 구축. DID 분석으로 대조지역 대비 200% 개선 증명. Python 자동화 파이프라인이 공식 가이드라인으로 채택됨.

3단계 분석 프로세스
  • [Stage 1] 원천 데이터 전수조사 — 1,703명 동일 ID 기준 데이터 수집, 주소지 수동 대조 및 수천 장 설문지 교차 검증
  • [Stage 2] Python 파이프라인 자동화 — 변수 코딩, 결측치 전처리, 변수 정의 일괄 자동화, 재현성을 위한 코딩 매뉴얼 수립
  • [Stage 3] 패널 DB & DID 실험 설계 — 환경 변수 통제 완료, Paired t-test, McNemar, DID 분석 완료

부산시 응급의료 취약지수 분석 — 보건 정책 기준 수립

부산대 의과대학 연구원 · 부산광역시 총괄

부산시 정책 채택

부산시 고령화 대비 3대 질환 사망 증가 원인 분석. 20여 개 복합 변수를 통합할 때 발생하는 다중공선성과 블랙박스화 문제를 해결하기 위해 상관관계 히트맵 + Z-score + Estimate 기반 지수 로직을 직접 설계.

분석 3단계
  • [Step 1] 상관관계 히트맵 (Correlation Heatmap) — 20여 개 변수 간 중복·상관 구조 시각화로 다중공선성 사전 차단
  • [Step 2] Z-score 스케일 표준화 — 출처 다른 변수들의 단위 차이 제거
  • [Step 3] Estimate 기반 취약지수 설계 — 지역별 변수값/SE²로 통계 신뢰도 반영한 지수 로직 직접 개발
결과 · 팀 이견 조율
  • 질환별 다중 고위험 지역 탐지, 부산시 보건정책 기초 자료로 채택
  • 고위험군 맞춤형 응급의료 자원 배분 모델 제안
  • QGIS + Tableau 공간 시각화 — 비전문가(정책 담당자) 즉시 활용 가능한 보고서
  • 샘플 데이터 기반으로 팀 이견 먼저 조율 후 전체 분석 진행
